# 面试常见问题和回答 - 行为篇
#### 请介绍一下你自己
控制在1-3分钟。教育背景→实习/项目经历→技能与岗位匹配→求职意向。突出与岗位相关的亮点，不要复读简历，用关键词引导面试官追问你准备好的部分。

#### 你的优点和缺点是什么？
优点：结合岗位需求，举例说明。缺点：选不影响工作的，并说明如何改进。例如"有时追求完美导致纠结细节，后来学会设置Deadline，优先完成核心再优化"。

#### 遇到过什么困难，如何解决的？
选技术或协作中的真实案例。描述背景、困难点、你的分析、采取的行动、结果与反思。体现解决问题能力和成长。

#### 为什么选择我们公司？
结合公司业务、技术栈、文化，说明与个人职业规划的契合。可提到产品、技术方向、发展空间。避免只说待遇好。
