# 面试常见问题和回答 - 技术篇
#### Java中HashMap的实现原理？
数组+链表+红黑树。根据key的hashCode计算数组下标，发生冲突用链表法，链表长度超8转红黑树。扩容时容量翻倍，元素rehash。线程不安全，多线程用ConcurrentHashMap。

#### 如何理解Spring的IOC和AOP？
IOC：控制反转，对象的创建和依赖由容器管理，降低耦合。通过依赖注入(DI)实现。AOP：面向切面，将横切关注点如日志、事务从业务中分离，通过代理实现。

#### 数据库索引为什么要用B+树？
B+树多路平衡，树高低，减少磁盘IO。叶子节点存数据且有序链表串联，适合范围查询。相比B树，非叶子节点只存索引，单节点可存更多key。

#### 如何设计一个高并发的秒杀系统？
限流削峰、缓存预热、库存扣减用Redis或MQ异步、防止超卖(分布式锁或乐观锁)、读写分离、动静分离、CDN。将瞬时流量分散，保护数据库。
