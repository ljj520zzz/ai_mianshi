# 面试常见问题和回答 - 简历篇
#### 如何写好项目经历描述？
采用STAR法则：情境(Situation)、任务(Task)、行动(Action)、结果(Result)。明确项目背景、你的角色、具体做了什么、量化成果。例如"负责XX系统优化，通过引入缓存和SQL优化，将接口响应时间从2秒降至200ms，QPS提升3倍"。避免泛泛而谈，用数据说话。

#### 简历上的项目经验太少怎么办？
优先写课程设计、毕设、开源贡献、个人作品。突出技术栈、解决的问题、你的贡献。可做小项目练手，如爬虫、博客、工具脚本，写清楚技术实现。实习、兼职中涉及技术的部分也可提炼。

#### 如何回答“介绍一下你的项目”？
1分钟版：项目是什么、你的角色、核心技术、突出成果。准备3-5个常见追问：为什么这么做、遇到什么难点、如何解决、有什么收获。提前演练，确保逻辑清晰。

#### 简历上写不熟悉的技术会被问到吗？
会。只写你真正了解并能说清的技术，宁可少写也要保证能答上来。写上的每一项都可能被深挖，提前准备对应的原理和应用场景。
